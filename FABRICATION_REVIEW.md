# TurnCount fabrication review

Reviewed 2026-10-02. Target: JLCPCB, 48 mm circular PCB, two layers,
1.6 mm FR4, 1 oz copper. This is a prototype review, **not an assembly release**.

## Source fixes

All design changes are in tscircuit TSX. Manufacturing files are generated by
the pinned CLI; no generated Gerber or KiCad geometry is patched.

- Move USB-C 0.7 mm inward. The nominal selected OBJ model has about
  0.26 mm radial clearance inside the circle. Enclosure and production
  tolerances are still to be established.
- Use 0.30 mm drills and 0.60 mm via pads, with both sides tented. These give
  a 0.15 mm annular ring and avoid reliance on small-via surcharge options.
  JLCPCB's component plated-hole annular-ring rule is distinct from its via rule.
- Move charger and regulator bypass capacitors closer to their pins. Add
  solid ground pours on both layers and four ground stitching vias around
  the charger, outside its solderable exposed pad.
- Generate charger perimeter and exposed-pad stencil apertures in native
  tscircuit. The pinned exporter omits paste for pill/polygon pads. Equivalent
  rounded rectangles preserve the imported pill copper; contained rectangular
  pads generate paste without extending copper beyond the original lands.
  Sixteen perimeter apertures are 0.60 × 0.24 mm. Two adjoining EP apertures
  cover approximately 83% of its chamfered copper area. TI's example uses
  approximately 85% and a 0.125 mm stencil; assembler review is required.
- Normalize four nearly rectangular USB power/ground pads to rectangles,
  differing from the imported outline by less than 0.0002 mm. A 0.05 mm
  paste reduction creates native apertures. Preserve the selected models.
- Keep probe lands bare, excluded from assembly and without stencil paste.
  Move TP6 to clear a routed reset via. Use routing hints for USB VBUS and
  the encoder push signal to place layer changes outside solder lands.
- Apply Raytac's antenna exclusion on both layers through to the board edge,
  and its separate top-only exclusion under the module. Omit unused pads
  40/41 as Raytac permits. Correct the existing STEP model's placement datum
  and use its reachable remote URL.

## Electrical and sourcing review

- TI charger pin assignments, BAT/OUT pairing, exposed-pad ground, USB100
  mode, charge-current resistor, TS sensor and default timer/termination
  configuration were checked against the BQ24074 datasheet.
- USB CC1/CC2 each have an independent 5.1 kΩ ground pull-down. Both VBUS
  contacts are supplied; ground and shell contacts connect to ground.
- USB_5V, VBAT, VSYS, V3V0 and GND remain distinct. The radio receives the
  3.0 V regulator output rather than the 4.2 V battery or 4.4 V USB-powered
  system rail. TPS7A02 pin assignments were checked against TI's datasheet.
- Raytac Version N confirms the connected module pin numbers: VDD 11;
  grounds 1/12/24/39; encoder GPIO 25/26/27; reset 35; SWD clock/data 36/37.
  Its recommended small lands are 1.4 × 0.4 mm on 0.7 mm pitch and large
  grounds are 1.4 × 0.8 mm, matching the adapted footprint within rounding.
- The generated BOM contains 28 populated designators and 14 distinct
  JLCPCB codes with indicative stock at review time. **The Raytac module
  has no verified JLCPCB listing**: searches for both MDBT42Q-512KV2 and
  MDBT42Q returned no results. No substitute part code has been assigned.
  Stock must be refreshed at order time.
- Generic passive footprint lint compares alternate land geometries and
  reports differences. Selected values, package sizes and the actual
  exported copper are checked separately; assembler land-pattern and CPL
  orientation approval remain required.

## Remaining release gates

### Radio replacement found

JLCPCB search by exact code **C2931350** returns **u-blox ANNA-B112-00B**,
with indicative stock of 40 and a displayed price of approximately US$7.69 at
review time. The manufacturer-authored [ANNA-B112 R12 datasheet](https://datasheet.lcsc.com/datasheet/pdf/3a5d418e3b9c1983dcafdd9f72dbadbd.pdf?productCode=C2931350)
confirms a **6.5 × 6.5 × 1.2 mm** nRF52832 module, 1.7–3.6 V operation and
SWD access. Section 1.5.2 explicitly permits custom firmware on any variant
after erasing module memory; the factory u-connectXpress firmware is not the
application required by this counter.

This is the preferred replacement candidate for low height. It requires a new
52-pad footprint, GPIO remapping (P0.12/P0.13 are not exposed), power/debug
wiring and manufacturer antenna tuning-strip geometry on the carrier board.
The internal antenna is not a self-contained drop-in RF layout. Obtain and
follow integration manual UBX-18009821 before implementing it. Its internal
DC-DC hardware and low-frequency clock configuration must be reviewed afresh.
The current source still uses Raytac; this section records discovery, not an
implemented module substitution. The 40-unit stock is a prototype supply,
not an established production supply commitment.

An alternative exact-code listing is **Ebyte E73-2G4M08S1C, C356849**:
nRF52840, 18 × 13 mm listed package, indicative stock 1,431 and displayed
price approximately US$8.18. It occupies more PCB area and needs its own
datasheet/layout verification. The listed E73-2G4M04S1B (C411306) is
28.7 × 17.5 mm and is a poor fit for our small board. E104-BT5032A
(C518912) is listed at 16 × 11.5 mm, but custom-firmware access has not been
verified; factory UART firmware alone is not enough for direct encoder input.

### Release checklist

1. **Radio sourcing:** select a programmable, suitable JLCPCB-listed radio
   module and redesign its footprint/pinout if complete JLCPCB assembly is
   required. The current Raytac cannot be represented as an available JLC part.
2. **Battery:** choose an actual protected 1S conventional LiPo, 4.2 V full
   charge, with compatible pack-mounted 10 kΩ NTC. Verify charge-current
   rating, temperature curve, protection, connector polarity and harness.
   The centered 20 × 30 mm reserve and 3 mm thickness/200 mAh targets do not
   establish that a purchasable pack fits. Add insulation and swelling space.
3. **Encoder:** GT-EVA01AA-L1 is rotatable via its square socket and has
   12 pulses/12 detents plus push. Its 50 mA/12 V rating does not specify
   minimum reliable current. Obtain G-Switch qualification for approximately
   30 µA closed-contact sensing or perform suitable life/environment testing.
4. **Capacitors and thermal behavior:** verify effective BAT/OUT capacitance
   remains at least 4.7 µF over bias, temperature and tolerance. Verify the
   regulator's effective output capacitance against TI's limits. Approve
   stencil/reflow and measure charger temperature with the actual battery,
   enclosure and worst-case operating load.
5. **Mechanical/RF:** approve the knob stem, locating pegs, connector access,
   pouch mounting, wiring and full tolerance stack. The pack connector is
   approximately 5.5 mm tall, taller than the 3.5 mm encoder body. Test RF
   with the intended cell, magnets, phone and enclosure; copper exclusion
   alone does not establish antenna performance.
6. **Firmware:** implement decoding/debounce, BLE, persistence and power
   behavior. With no external 32.768 kHz crystal, use the calibrated internal
   LFRC clock. With no DC-DC inductors, use nRF52832 LDO mode and leave DCC
   unused. Confirm programming and actual assembled module orientation.
7. **Assembly review:** confirm BOM/CPL pin-1 orientation, especially the
   radio and connectors, and approve generic passive lands and mask/stencil
   production settings. Green solder mask and ENIG are proposed for the
   fine-pitch charger and USB lands; no order has been placed.

## Independent KiCad export limitations

The current exporter marks every keepout as prohibiting tracks, vias, pads,
footprints and pours, without preserving native `excludeRefs`. This causes
own-component footprint keepout reports for USB and the radio. Ground pours
with holes are exported as triangulated filled polygons, producing numerous
isolated-copper reports and keepout contacts on outer zone boundaries.

Do not treat the KiCad export as a clean release artifact. Inspect its DRC
counts and use the actual Gerber connectivity/exclusion checks to distinguish
translation issues from physical manufacturing faults. Silkscreen overlaps
and fine copper-sliver warnings still require assembler review.

Final KiCad DRC reports eight keepout errors, one missing connection between
the exported top/bottom ground zones, 199 isolated-copper warnings, 44 library
footprint warnings, 11 silkscreen overlaps, three mask-clipped silkscreen
warnings and three copper-sliver warnings. The Gerber check verifies every
intended net's actual physical connectivity, including the ground pads, and
both RF exclusions. The KiCad zone reports are not a clean DRC pass.

## Reproduce

The CLI requires Bun on PATH. Python checks require `gerbonara` and `shapely`.
Output paths below assume this workspace; change them for another checkout.

```sh
npm run typecheck
npx tsci check netlist
npx tsci check schematic-placement
npx tsci check placement
npx tsci build --pcb-png --schematic-png
npm run check:power
npm run check:fabrication  # fails until U1 has a real JLCPCB code
npx tsci check shorts dist/index/circuit.json
npx tsci export dist/index/circuit.json -f gerbers -o /workspace/turncount/dist/fab-audit.zip
python -m zipfile -e dist/fab-audit.zip dist/fab-audit
python scripts/check-gerbers.py dist/fab-audit dist/index/circuit.json
npx tsci export dist/index/circuit.json -f kicad_pcb -o /workspace/turncount/dist/fab-audit.kicad_pcb
cp scripts/jlcpcb-2layer-1oz.kicad_dru dist/fab-audit.kicad_dru
kicad-cli pcb drc dist/fab-audit.kicad_pcb --format json -o dist/fab-audit.drc.json
```

Keep generated files under ignored `dist/`. Remove ZIP bundles and snapshots
before publishing the source package.

## Prototype bring-up

Check USB power in both plug orientations, input-current limiting, regulated
rail voltage, battery-only operation and load handoff. Check NTC fault response,
charge termination and temperatures with the selected pack. Program over SWD
using the correct LFRC/LDO settings. Measure input bounce, direction, detent
count and sensing reliability. Measure idle/connected/rotation current before
making battery-life claims; then test the completed mechanical/RF assembly.
